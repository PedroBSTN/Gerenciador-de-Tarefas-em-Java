# Gerenciador-de-Tarefas-em-Java
Projeto simples desenvolvido em Java utilizando conceitos de Programação Orientada a Objetos (POO).

# Funcionalidades
Adicionar tarefas

Listar tarefas

Marcar tarefas como concluídas

Interface simples via terminal

# Tecnologias

Java

ArrayList

Scanner

POO

# Como executar

javac GerenciadorDeTarefas.java

java GerenciadorDeTarefas
